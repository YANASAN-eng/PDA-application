# デザインの参照資料

Claude Design などで作った画面のモックアップを、**画面ごとのフォルダ**に置く。
実装はここを見ながら行い、色・余白・角丸などの値を `src/pda/web/templates/base.html` の CSS 変数に写す。

- モックアップは**参照用**。そのままアプリに組み込まない(`support.js`・`vendor/` は表示のための部品で、デザインの一部ではない)
- 見るとき: このフォルダで `python -m http.server` を実行し、ブラウザで各フォルダの `*.dc.html` を開く(file:// では動かないことがある)
- 新しいモックアップをもらったら、`docs/design/<画面名>/` に置いて、この表に足す

| フォルダ | 画面 | 受け取った日 | 反映 |
|---|---|---|---|
| `memo/` | メモ(スマホ幅 390px) | 2026-11-16 | 共通の決まり(色・書体・カード・タブバー)を全画面に反映。メモ画面そのものは未実装 |

## モックアップから読み取った共通の決まり(2026-11-16)
| 要素 | 値 |
|---|---|
| 背景 / 文字 / 薄い文字 | `#FFFAEC` / `#4A3540` / `#7D6470` |
| 強調色(主ボタン) | `#B4501C` |
| 書体 | Zen Maru Gothic(Google Fonts。読めないときは sans-serif) |
| カード | 白または淡い色(`#FFE1EA` `#E6E0FA` `#DDF3EA` `#FFEFC2`)、角丸、影 `0 3px 0 <少し濃い色>` |
| ボタン・タグ | 錠剤型(`border-radius: 999px`)。タグは白地に `#EADDB0` の枠 |
| ナビ | 画面下のタブバー(今日・ToDo・予定・メモ・ニュース)。今の画面は `#FFF0B8` で強調 |
