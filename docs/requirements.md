# 要件と決定事項

このファイルが要件の正本。決定には日付と理由を残す。

## ミッション・バリュー(⚠ 案 — ユーザー確認待ち)
CLAUDE.md の同名の節と同じ内容を保つ。

- **ミッション**: 自分の毎日の予定・やることと、世界の技術・科学の動きを、ひとつの場所で短時間に把握できるようにする
- **バリュー**
  1. 短時間で済む(量より選別)
  2. 出典に戻れる(要約には元記事リンクと配信元を必ず付ける)
  3. 自分のデータは自分の手元に(予定・メモはローカル。外部送信はニュース要約依頼のみ)
  4. 費用を意識する(同じ記事を二度要約しない・件数上限)
  5. 壊れにくく、直しやすい(TDD、フィード単位の障害分離)

## 機能一覧(初期スコープ)
### ToDo
- タイトル、期限(任意)、完了フラグ
- 未決定: 優先度を持つか / 繰り返しタスクを扱うか

### 予定
- タイトル、開始日時、終了日時(任意)、場所・メモ(任意)
- 「今日の予定」を表示
- 未決定: 終日予定の扱い / 繰り返し予定を扱うか

### メモ
- タイトル、本文、作成日時・更新日時
- 未決定: タグや検索が要るか

### ニュース
- 1 日 1 回、設定したフィードから記事を取得
- IT・科学に関係する記事に絞る
- 記事ごとに日本語要約を作り、配信元・元記事リンクと一緒に表示
- 未決定: 対象フィードの一覧 / 絞り込み方法(キーワード or Claude に判定させる)/ 1 日の要約件数の上限 / 重複記事(同じ話題の別記事)の扱い

## 費用方針
- 2026-11-15: 費用は最小に抑える(ユーザーの生活費に響かないこと)。手段はプロンプト・設計の工夫 + モデル選択

- 未決定(本物に切り替えるとき決める): 既定モデル(候補: Haiku 5.5)/ 月の上限額(Console の利用上限にも設定する)
